# JUFTECH 中文版设计说明

## 目标

在不改变现有英文站视觉与英文 URL 的前提下，为 `https://jufauto.com` 增加完整简体中文版。中文统一使用 `/zh` 前缀，并与英文共享产品、文章、询盘、后台和租户数据。

## 约束

- 英文继续作为默认语言，现有英文 URL 不变。
- 中文 URL 使用 `/zh`、`/zh/products`、`/zh/products/<slug>` 等结构。
- 语言切换器尽量保留当前页面与查询参数。
- 数据读取遵循“请求语言 → 默认英文 → 首个非空语言”回退。
- 产品、文章、Metadata、Canonical、Open Graph、Schema 与 Sitemap 必须使用同一 locale。
- 中英文互相输出 `hreflang`，英文首页作为 `x-default`。
- 品牌名、型号、数字、单位、标准和认证编号保持原样；禁止新增无法证明的事实。
- 全部中文内容继续遵守禁用质保、保修、`warranty`、`guarantee` 的项目规则。
- 不改造现有视觉体系，不重新调用 v0，不更换客户真实图片。

## 实现选择

采用共享 locale 层：英文与中文路由调用同一组页面渲染函数、组件和数据库映射，通过 `locale` 参数选择文案与 `*_i18n` 数据。根布局根据请求路径设置正确的 `html lang`，页头、页脚、表单和交互组件从同一语言字典读取文本。

未采用整站复制，因为复制页面会造成后续功能与 SEO 双份维护；未采用仅客户端替换文字，因为它不能可靠输出服务端 Metadata、Schema 与正确的 `html lang`。

## 验收

- 英文现有路由无回归；中文静态页、产品页、文章页均可访问。
- 中文页面无残留的界面英文文案，品牌名和专业型号除外。
- 两种语言的 Canonical、hreflang、Schema、Sitemap、HTML `lang` 正确。
- 后台租户启用 `en`、`zh-CN`，产品与文章中文字段可保存并前台回读。
- 桌面端和 390px 手机端语言切换、导航、表单、产品与文章页面通过真实浏览器验证。
